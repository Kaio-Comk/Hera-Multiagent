# Security Policy

## Supported Versions
| Version | Supported |
| --- | --- |
| Latest release / main | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security issue or vulnerability, please contact the maintainer directly or use GitHub Private Vulnerability Reporting. Do not report security vulnerabilities in public issues.

## Code agent

The terminal code agent (`hera chat --agente`) has its own threat model, modes, and honest limits: see [docs/SECURITY-AGENT.md](docs/SECURITY-AGENT.md).
